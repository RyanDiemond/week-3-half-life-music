# week-3-half-life-music
<h2>This is my Midi Keyboard project. It is a musical board just like a piano.</h2>
<h4>Midi Keyboard is a board with copper exposed parts that allow you to touch it and it will make noise, or you can click some of the buttons that will also turn on a light or a slider that puts different lights on also.</h4>

This is my schematic: it has a XIAO ESP32 S3 board, with a slider with two lights on each end, and two buttons that also have lights, and exposed copper parts that allow you to click them.
